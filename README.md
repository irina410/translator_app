## Translator App

Android-приложение для перевода слов с английского на русский с сохранением истории и избранного.

Проект выполнен в рамках тестового задания (kaspersky-android-2025)
Источник перевода — Skyeng Dictionary API.

---

## Описание

Приложение позволяет:

* вводить английские слова и получать перевод на русский;
* сохранять историю переводов локально;
* добавлять и удалять слова из избранного;
* просматривать список избранных слов на отдельном экране.

Хранение данных реализовано локально с использованием Room.
Работа с сетью выполнена через REST API Skyeng.

---

## Функциональные возможности

### Основной экран

* ввод слова для перевода;
* получение одного варианта перевода;
* отображение истории переводов;
* удаление слова из истории по долгому нажатию;
* добавление / удаление слова из избранного.

### Экран избранного

* отображение списка слов, добавленных в избранное;
* удаление слова из избранного;
* удаление слова из базы данных.

## Используемые технологии

* Язык программирования: Kotlin
* UI: Jetpack Compose
* Асинхронность: Kotlin Coroutines, Flow
* Архитектура: MVVM
* Работа с сетью: Retrofit
* База данных: Room
* Dependency Injection: Hilt

---

## Архитектура

Проект построен с разделением на слои:

* **data**

  * local — Room (Entity, Dao, Database)
  * remote — работа с Skyeng API
  * repository — реализация репозитория
* **domain**

  * model — доменные модели
  * repository — интерфейсы
* **ui**

  * translator_screen — экран перевода и истории
  * favorites_screen — экран избранного
* **di**

  * модули Hilt для базы данных, сети и репозитория

ViewModel используется для управления состоянием UI и бизнес-логикой.

---

## API

Для перевода используется Skyeng Dictionary API:
[https://dictionary.skyeng.ru/doc/api/external](https://dictionary.skyeng.ru/doc/api/external)

Из полученного ответа используется один любой вариант перевода.

---

## Хранение данных

История переводов и избранные слова сохраняются локально в базе данных Room.
Каждое слово содержит:

* английский вариант;
* перевод;
* флаг избранного;
* время перевода.
